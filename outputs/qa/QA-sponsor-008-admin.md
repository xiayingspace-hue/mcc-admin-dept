# 赞助商管理 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |

| QA-sponsor-008-admin-001 | AC-001 | Become a Sponsor 表单已打开 | 公司名称/联系人/职位/邮箱/电话任一留空，点击提交 | 阻止提交并提示对应字段 |
| QA-sponsor-008-admin-002 | AC-002 | 其余必填项已填 | 邮箱填写为不合法格式（如缺少 @） | 阻止提交并提示邮箱格式不合法 |
| QA-sponsor-008-admin-003 | AC-003 | 表单所有必填项均已合法填写 | 点击提交 | 展示感谢页文案；该线索出现在行政"赞助商管理"列表中，初始跟进状态为"待联系" |
| QA-sponsor-008-admin-004 | AC-004 | 赞助商管理中存在 2 条"待联系"记录 | 打开任意管理端页面，观察左侧导航 | "赞助商管理"导航项显示角标"2" |
| QA-sponsor-008-admin-005 | AC-004 | 赞助商管理中所有记录均已标记"已联系" | 打开任意管理端页面，观察左侧导航 | "赞助商管理"导航项角标消失 |
| QA-sponsor-008-admin-006 | AC-005 | 某赞助线索状态为"待联系" | 点击"标记已联系" | 状态变为"已联系"，导航角标数字 -1 |
| QA-sponsor-008-admin-007 | AC-005 | 某赞助线索状态为"已联系" | 点击"标记待联系" | 状态变为"待联系"，导航角标数字 +1 |
| QA-sponsor-008-admin-008 | AC-006 | 存在多个活动的赞助线索 | 按活动筛选为其中一个活动 | 仅展示该活动下的赞助线索，切换筛选立即生效，无需刷新 |
| QA-sponsor-008-admin-009 | §9 五态-loading | 模拟赞助商管理列表接口响应延迟 | 打开赞助商管理页面 | 展示骨架屏，而非空白或卡死 |
| QA-sponsor-008-admin-010 | §9 五态-empty | 某活动尚无任何赞助线索 | 按该活动筛选赞助商管理列表 | 展示"该活动尚无赞助线索"文案，而非空白表格 |
| QA-sponsor-008-admin-011 | AC-007 | 用户端 Become a Sponsor 表单已打开 | 依次选择 请选择、Silver、Gold、Platinum、Custom | 只有选 Custom 时下方出现"自定义赞助说明"输入框；其余情况不显示 |
| QA-sponsor-008-admin-012 | AC-008 | 表单必填项已填，等级选 Custom | 说明留空，点击提交；再只输入空格后提交 | 两次都被阻止并提示需要填写自定义赞助说明 |
| QA-sponsor-008-admin-013 | AC-008（边界） | 同上 | 说明输入恰好 200 个字符，再输入 201 个字符 | 200 个字符可提交，计数显示 200 / 200；201 个字符计数变红，被阻止并提示，已输入内容不被截断 |
| QA-sponsor-008-admin-014 | AC-008 | 同上 | 逐字输入说明，观察输入框下方 | 实时显示"已输入 / 200"，清空后回到 0 / 200 |
| QA-sponsor-008-admin-015 | AC-009 | 等级选 Custom，说明已填"赞助 S$20,000 并设展位" | 改选 Gold，提交表单；再重新选回 Custom | 提交成功，管理端该线索等级只显示 Gold，没有说明；重新选回 Custom 时输入框是空的 |
| QA-sponsor-008-admin-016 | AC-010 / AC-003 | 访客提交等级为 Custom、说明为"赞助 S$20,000 并设展位" | 行政打开赞助商管理列表 | 该线索的"意向等级"列显示"Custom：赞助 S$20,000 并设展位"，状态"待联系" |
| QA-sponsor-008-admin-017 | AC-010（边界） | 一条 Custom 线索，说明 200 个字符；另一条说明恰好 2 行；再一条等级为 Silver | 打开赞助商管理列表 | 200 字的显示 2 行加省略号，悬停显示全文，行高不被撑高；恰好 2 行的完整显示；Silver 只显示 Silver |
| QA-sponsor-008-admin-018 | AC-011 / §8 校验（后端） | 直接调用提交赞助意向接口 | `tier=custom` 且分别不传说明、传空格、传 201 个字符；再传 `tier=gold` 同时带说明 | 前三种被拒绝并返回明确原因；`gold` 的请求成功，说明被忽略，列表里没有说明 |
| QA-sponsor-008-admin-019 | AC-012 | 行政打开赞助商管理，列表有数据，选"全部活动" | 点击"导出" | 下载一个 .xlsx，文件名为 `赞助商线索_全部活动_<今天日期>.xlsx` |
| QA-sponsor-008-admin-020 | AC-012 / §9 | 某活动下没有任何赞助线索 | 选该活动，查看"导出"按钮 | 按钮置灰、不可点击 |
| QA-sponsor-008-admin-021 | AC-013 | 活动 A 有 3 条线索，活动 B 有 2 条 | 选活动 A 导出；再选"全部活动"导出 | 前者只含 A 的 3 条，文件名含活动 A 名称；后者含 5 条 |
| QA-sponsor-008-admin-022 | AC-013 | 线索总数超过一页（如 45 条，每页 20 条） | 在第 1 页点击导出 | 导出文件含全部 45 条，不只是当前页的 20 条 |
| QA-sponsor-008-admin-023 | AC-014 | 一条 Custom 线索：说明 200 个字符，留言 500 字，含换行 | 导出后打开文件 | 11 列依次为所属活动、公司名称、联系人、职位、邮箱、电话、意向赞助等级、自定义赞助说明、留言 / 特殊需求、提交时间、跟进状态；自定义说明和留言为完整全文；没有"操作"列 |
| QA-sponsor-008-admin-024 | AC-014 | 一条等级为 Gold、无留言的线索 | 导出后查看 | 意向赞助等级为 Gold，自定义赞助说明单元格为空；留言单元格为空（不是"—"）；邮箱、电话各占一列 |
| QA-sponsor-008-admin-025 | AC-014 | 一条线索提交于新加坡时间 2026-09-20 11:15，状态已联系 | 导出后查看 | 提交时间为 `2026-09-20 11:15`；跟进状态为"已联系"（中文） |
| QA-sponsor-008-admin-026 | AC-015 | 列表页停留着，期间另一位行政把某线索标记为"已联系" | 不刷新列表直接点击导出 | 导出里该线索的状态是"已联系"（与后端最新一致） |
| QA-sponsor-008-admin-027 | AC-016 | 非行政账号 | 查看赞助商管理页面；直接调用导出接口 | 看不到导出按钮；接口被后端拒绝，不返回任何数据 |
