# 活动创建、审批与生命周期 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-activity-001-admin-001 | AC-001 | 进入创建活动步骤一 | 不填任何字段，点击"下一步" | 全部必填字段高亮报错，不跳转到步骤二 |
| QA-activity-001-admin-002 | AC-002 | 步骤一其余必填项已填 | 结束时间设为早于开始时间 | 独立报错"结束时间需晚于开始时间"，不因其余字段合法而放行 |
| QA-activity-001-admin-003 | AC-003 | 步骤三，预算填 60000 | 提交审批 | 审批进度显示包含"财务审批"节点 |
| QA-activity-001-admin-004 | AC-003 | 步骤三，预算填 30000 | 提交审批 | 审批进度不包含"财务审批"节点 |
| QA-activity-001-admin-005 | AC-004 / §8 校验 | 活动处于审批中，当前用户是待处理节点审批人 | 点击"驳回"但不填写意见 | 阻止提交，提示需填写驳回意见 |
| QA-activity-001-admin-006 | AC-004 | 活动已被驳回 | 发起人编辑后重新提交 | 活动状态回到"审批中"，审批链从第一个节点重新开始 |
| QA-activity-001-admin-007 | AC-005 | 活动状态为"已发布" | 打开活动列表 | 该行操作列只有"查看详情""下线"，无"编辑" |
| QA-activity-001-admin-008 | AC-006 | 活动状态为"草稿" | 点击"删除" | 弹出二次确认；确认后该活动记录从列表移除（硬删除） |
| QA-activity-001-admin-009 | AC-007 | 活动状态为"审批中" | 打开活动详情页 | "外部可见性"字段旁不显示"修改"入口 |
| QA-activity-001-admin-010 | AC-007 | 活动状态为"已发布" | 点击"外部可见性"旁的"修改"，切换选项并保存 | 字段值立即更新；活动主状态不变；不产生新的审批记录 |
| QA-activity-001-admin-011 | AC-008 | 当前用户是活动发起人，从"活动管理"列表点击"查看详情" | 打开详情页 | 展示"撤回申请"，不展示"通过/驳回" |
| QA-activity-001-admin-012 | AC-008 | 当前用户是待处理节点审批人，从统一待办列表点击对应任务 | 打开详情页 | 展示"通过/驳回"+意见输入框，不展示"撤回申请" |
| QA-activity-001-admin-013 | §9 五态-empty | 当前行政账号从未创建过任何活动 | 打开活动列表 | 展示"从未创建过活动"文案，而非空白表格 |
| QA-activity-001-admin-014 | §9 五态-empty2 | 已有活动，筛选条件设为不存在的组合 | 打开活动列表并应用筛选 | 展示"没有符合筛选条件的活动"文案，与 013 文案不同 |
| QA-activity-001-admin-015 | §9 五态-error | 模拟列表接口返回失败 | 打开活动列表 | 展示错误原因 + 重试按钮，点击重试重新发起请求 |
| QA-activity-001-admin-016 | §9 五态-overflow | 存在标题超长的活动 | 打开活动列表 | 超长标题不撑破表格布局，采用截断或换行处理 |
