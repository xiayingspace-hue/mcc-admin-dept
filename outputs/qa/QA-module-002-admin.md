# 活动模块配置与模块库 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-module-002-admin-001 | AC-001 | 创建活动步骤二，模块勾选均未启用 | 勾选启用"涂鸦评选" | 该模块的专属配置字段区域展开显示 |
| QA-module-002-admin-002 | AC-001 | "涂鸦评选"已勾选并填写了提交/投票截止时间 | 取消勾选"涂鸦评选" | 配置区域收起；保存后不创建该活动模块记录，已填写的值不提交 |
| QA-module-002-admin-003 | AC-002 | 涂鸦评选已启用 | 投票截止时间设为与提交截止时间相同 | 保存时报错阻止 |
| QA-module-002-admin-004 | AC-002 | 涂鸦评选已启用 | 投票截止时间设为早于提交截止时间 | 保存时报错阻止 |
| QA-module-002-admin-005 | AC-003 | 任一模块已启用 | 该模块"开始展示时间"设为晚于其自身某截止时间字段 | 保存时报错阻止 |
| QA-module-002-admin-006 | AC-004 | 模块库中某模块类型已被 N（N≥1）个活动使用 | 点击该模块卡片"查看使用记录" | 展开的活动名称列表数量与展示的"已被 N 个活动使用"一致 |
| QA-module-002-admin-007 | AC-004 / §9 五态-empty | 模块库中某模块类型从未被任何活动使用 | 打开模块库 | 该模块卡片显示"暂未被使用"，而非报错或空白 |
| QA-module-002-admin-008 | AC-005 | 打开模块库页面 | 检查页面全部可交互元素 | 不存在任何"新增模块类型"的按钮或表单入口 |
| QA-module-002-admin-009 | §8 校验 | 寄语墙已启用，活动开始时间已知 | 留言截止时间设为早于活动开始时间 | 保存时报错阻止 |
| QA-module-002-admin-010 | §8 校验（联动） | 活动"外部可见性"已设为"仅内部可见" | 寄语墙"允许外部人士留言"开关设为"是"并保存 | 待 §11 已知缺口（阻止保存还是仅警告，由行政在开发排期前决定）明确后细化本用例，当前仅验证系统给出某种形式的提示，不判定具体拦截方式 |
| QA-module-002-admin-011 | §9 五态-loading | 模拟模块库接口响应延迟 | 打开模块库 | 展示骨架屏，而非空白或卡死 |
