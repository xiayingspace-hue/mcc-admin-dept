# 活动模块配置与模块库 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-module-002-admin-001 | AC-001 | 创建活动步骤二，模块勾选均未启用 | 勾选启用"Celebrations" | 该模块的专属配置字段区域展开显示 |
| QA-module-002-admin-002 | AC-001 | "Celebrations"已勾选并填写了开始展示时间 | 取消勾选"Celebrations" | 配置区域收起；保存后不创建该活动模块记录，已填写的值不提交 |
| QA-module-002-admin-005 | AC-003 | 任一活动模块（Celebrations/寄语墙）已启用 | 该模块"开始展示时间"设为晚于其自身某截止时间字段 | 保存时报错阻止 |
| QA-module-002-admin-006 | AC-004 | 模块库中某模块类型已被 N（N≥1）个活动或 Celebration 使用 | 点击该模块卡片"查看使用记录" | 展开的名称列表数量与展示的"已被 N 个活动/Celebration 使用"一致 |
| QA-module-002-admin-007 | AC-004 / §9 五态-empty | 模块库中某模块类型从未被任何活动或 Celebration 使用 | 打开模块库 | 该模块卡片显示"暂未被使用"，而非报错或空白 |
| QA-module-002-admin-008 | AC-005 | 打开模块库页面 | 检查页面全部可交互元素 | 不存在任何"新增模块类型"的按钮或表单入口 |
| QA-module-002-admin-009 | §8 校验 | 寄语墙已启用，活动计划开始时间已知 | 留言截止时间设为早于活动计划开始时间 | 保存时报错阻止 |
| QA-module-002-admin-010 | §8 校验（联动） | — | — | 【已废止，编号留空不重排】寄语墙的"允许外部人士留言"属性已取消，不再有与"外部可见性"的联动校验（见 `identity-009-admin`） |
| QA-module-002-admin-011 | §9 五态-loading | 模拟模块库接口响应延迟 | 打开模块库 | 展示骨架屏，而非空白或卡死 |
| QA-module-002-admin-012 | §9 页面清单 | 创建活动步骤二 | 检查页面全部可勾选的模块项 | 仅展示Celebrations/寄语墙两项，不出现"CEO致辞""历史时间轴""报名信息""涂鸦展示" |
| QA-module-002-admin-013 | AC-006 | 打开模块库页面 | 查看全部模块卡片 | 只有Celebrations、涂鸦展示、寄语墙、报名信息四张；没有 CEO 致辞、历史时间轴（也没有「文字描述」「图片展示」卡片） |
| QA-module-002-admin-014 | AC-006 | 创建活动步骤二 | 查看模块列表 | 只有Celebrations、寄语墙两项，没有 CEO 致辞、历史时间轴 |
| QA-module-002-admin-015 | AC-006 / §8 模块类型范围 | 创建或编辑草稿活动，直接调用保存活动模块配置的接口 | `modules` 里带上 `ceo_speech`（或 `timeline`），其余字段合法 | 整个请求被后端拒绝，配置不变；合法的模块也不会被保存 |
| QA-module-002-admin-016 | AC-006 / §8 模块类型范围 | 同上 | `modules` 里带上 `doodle_vote`、`registration` 或不存在的类型 | 同样整个请求被拒绝，配置不变 |
| QA-module-002-admin-017 | AC-006 | 同上 | `modules` 只带 `blog_list`、`wall` 的任意组合 | 保存成功 |
| QA-module-002-admin-018 | AC-004 / AC-006 | 打开模块库 | 查看四张卡片的「已被 N 个活动/Celebration 使用」 | 数字只统计这四类模块，已下线的两类不再出现在任何统计或使用记录列表里 |
