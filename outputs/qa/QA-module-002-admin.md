# 活动模块配置与模块库 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-module-002-admin-001 | AC-001 | 创建活动步骤二，模块勾选均未启用 | 勾选启用"CEO致辞" | 该模块的专属配置字段区域展开显示 |
| QA-module-002-admin-002 | AC-001 | "CEO致辞"已勾选并填写了开始展示时间 | 取消勾选"CEO致辞" | 配置区域收起；保存后不创建该活动模块记录，已填写的值不提交 |
| QA-module-002-admin-005 | AC-003 | 任一活动模块（CEO致辞/历史时间轴/周年博客列表/寄语墙）已启用 | 该模块"开始展示时间"设为晚于其自身某截止时间字段 | 保存时报错阻止 |
| QA-module-002-admin-006 | AC-004 | 模块库中某模块类型已被 N（N≥1）个活动或 Celebration 使用 | 点击该模块卡片"查看使用记录" | 展开的名称列表数量与展示的"已被 N 个活动/Celebration 使用"一致 |
| QA-module-002-admin-007 | AC-004 / §9 五态-empty | 模块库中某模块类型从未被任何活动或 Celebration 使用 | 打开模块库 | 该模块卡片显示"暂未被使用"，而非报错或空白 |
| QA-module-002-admin-008 | AC-005 | 打开模块库页面 | 检查页面全部可交互元素 | 不存在任何"新增模块类型"的按钮或表单入口 |
| QA-module-002-admin-009 | §8 校验 | 寄语墙已启用，活动计划开始时间已知 | 留言截止时间设为早于活动计划开始时间 | 保存时报错阻止 |
| QA-module-002-admin-010 | §8 校验（联动） | 活动"外部可见性"已设为"仅内部可见" | 寄语墙"允许外部人士留言"开关设为"是"并保存 | 待 §11 已知缺口（阻止保存还是仅警告，由行政在开发排期前决定）明确后细化本用例，当前仅验证系统给出某种形式的提示，不判定具体拦截方式 |
| QA-module-002-admin-011 | §9 五态-loading | 模拟模块库接口响应延迟 | 打开模块库 | 展示骨架屏，而非空白或卡死 |
| QA-module-002-admin-012 | §9 页面清单 | 创建活动步骤二 | 检查页面全部可勾选的模块项 | 仅展示 CEO致辞/历史时间轴/周年博客列表/寄语墙四项，不出现"报名信息""涂鸦展示" |

> 编号 003、004 空缺：原对应 AC-002（涂鸦展示投票/提交截止时间校验），随该模块挂载对象变更迁移至 `celebration-007-admin`，用例见 `QA-celebration-007-admin-*`，本文档不重排后续编号、不复用 003/004。
