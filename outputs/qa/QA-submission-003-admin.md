# 作品管理（涂鸦评选类模块） 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-submission-003-admin-001 | AC-001 | 上传作品表单，姓名已填 | 不选择图片，点击"上传作品" | 阻止提交，提示"作品图片"必填 |
| QA-submission-003-admin-002 | AC-001 | 上传作品表单，图片已选 | 不填姓名，点击"上传作品" | 阻止提交，提示"作者姓名"必填 |
| QA-submission-003-admin-003 | AC-002 | 某作品状态为"未发布" | 点击"发布" | 状态变为"已发布"，操作按钮变为"隐藏" |
| QA-submission-003-admin-004 | AC-003 | 某作品状态为"已发布"，当前票数为 N | 点击"隐藏" | 状态变为"已隐藏"，操作按钮变为"恢复"和"删除"，票数仍为 N |
| QA-submission-003-admin-005 | §5 状态机 | 某作品状态为"已隐藏" | 点击"恢复" | 状态变为"已发布" |
| QA-submission-003-admin-006 | §8 校验 | 某作品状态为"已发布" | 尝试删除（不先隐藏） | 删除操作被阻止或删除入口不可用 |
| QA-submission-003-admin-007 | §8 校验 | 某作品状态为"已隐藏" | 点击"删除" | 记录从列表移除（硬删除） |
| QA-submission-003-admin-008 | AC-004 | 存在多个 Celebration、多种状态的作品 | 筛选条件设为"Celebration=Q3团建营地站"+"状态=未发布" | 仅显示同时满足两个条件的作品 |
| QA-submission-003-admin-009 | AC-005 | 当前筛选条件为"状态=未发布" | 将其中一个作品状态改为"已发布" | 该作品立即从当前视图消失，无需手动刷新 |
| QA-submission-003-admin-010 | §9 五态-loading | 模拟作品列表接口响应延迟 | 打开作品管理页面 | 展示骨架屏 |
| QA-submission-003-admin-011 | §9 五态-empty | 该 Celebration 下从未上传过作品 | 打开作品管理页面 | 展示"从未上传过作品"文案 |
| QA-submission-003-admin-012 | §9 五态-empty2 | 该 Celebration 下已有作品，筛选条件设为不存在的组合 | 应用筛选 | 展示"没有符合筛选条件的作品"文案，与 011 文案不同 |
| QA-submission-003-admin-013 | `celebration-007-admin` AC-005 | 同一活动下有两个 Celebration，各自已发布若干作品并有投票数 | 分别打开两个 Celebration 各自的作品/投票视图 | 两者的作品列表、票数互不包含对方数据 |
| QA-submission-003-admin-014 | AC-006 | 某"已发布"作品当前票数为 N，当前用户未投过票 | 用户点击该作品的投票按钮 | 票数变为 N+1，按钮切换为"已投"状态 |
| QA-submission-003-admin-015 | AC-006 | 承 014，当前用户已对该作品投票，票数为 N+1 | 用户再次点击投票按钮 | 票数恢复为 N，按钮切换回"未投"状态（取消而非继续累加） |
| QA-submission-003-admin-016 | AC-006 | 承 015，用户刚取消投票，票数为 N | 用户第三次点击投票按钮 | 票数重新变为 N+1，按钮变回"已投"状态，全程不出现票数异常累加（如 N+2） |
| QA-submission-003-admin-017 | AC-007 | 同一 Celebration 下存在作品 A、B 均为"已发布"，当前用户未对任一作品投票 | 用户先对 A 投票，再对 B 投票 | A、B 的票数均各自 +1，两者互不影响；对 A 取消投票后 B 的投票状态不受影响 |
| QA-submission-003-admin-018 | §8 校验（投票） | 某作品状态为"未发布"或"已隐藏" | 用户查看该作品 | 不展示投票入口/投票按钮不可用，无法对该作品投票 |
