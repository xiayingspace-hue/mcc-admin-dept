# 作品管理（涂鸦评选类模块） 测试用例

| 用例编号 | 关联 AC/校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-submission-003-admin-001 | AC-001 | 上传作品表单，姓名已填 | 不选择图片，点击"上传作品" | 阻止提交，提示"作品图片"必填 |
| QA-submission-003-admin-002 | AC-001 | 上传作品表单，图片已选 | 不填姓名，点击"上传作品" | 阻止提交，提示"作者姓名"必填 |
| QA-submission-003-admin-003 | AC-002 | 某作品状态为"未发布" | 点击"发布" | 状态变为"已发布"，操作按钮变为"隐藏" |
| QA-submission-003-admin-004 | AC-003 | 某作品状态为"已发布"，当前票数为 N | 点击"隐藏" | 状态变为"已隐藏"，操作按钮变为"恢复"和"删除"，票数仍为 N |
| QA-submission-003-admin-005 | §5 状态机 | 某作品状态为"已隐藏" | 点击"恢复" | 状态变为"已发布" |
| QA-submission-003-admin-006 | §8 校验 | 某作品状态为"已发布" | 尝试删除（不先隐藏） | 删除操作被阻止或删除入口不可用 |
| QA-submission-003-admin-007 | §8 校验 | 某作品状态为"已隐藏" | 点击"删除" | 记录从列表移除（硬删除） |
| QA-submission-003-admin-008 | AC-004 | 存在多个活动、多种状态的作品 | 筛选条件设为"活动=Q3团建"+"状态=未发布" | 仅显示同时满足两个条件的作品 |
| QA-submission-003-admin-009 | AC-005 | 当前筛选条件为"状态=未发布" | 将其中一个作品状态改为"已发布" | 该作品立即从当前视图消失，无需手动刷新 |
| QA-submission-003-admin-010 | §9 五态-loading | 模拟作品列表接口响应延迟 | 打开作品管理页面 | 展示骨架屏 |
| QA-submission-003-admin-011 | §9 五态-empty | 该活动模块下从未上传过作品 | 打开作品管理页面 | 展示"从未上传过作品"文案 |
| QA-submission-003-admin-012 | §9 五态-empty2 | 该活动模块下已有作品，筛选条件设为不存在的组合 | 应用筛选 | 展示"没有符合筛选条件的作品"文案，与 011 文案不同 |
