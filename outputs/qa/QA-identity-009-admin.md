# 员工身份识别与参与限制 测试用例

| 用例编号 | 关联 AC / 校验规则 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| QA-identity-009-admin-001 | AC-001 | 员工从公司内部系统带令牌进入某 Celebration 详情页，报名开关、涂鸦展示开关均打开，未报名 | 查看「立即报名」、涂鸦投票按钮；进入活动页查看「写下你的寄语」 | 三个入口都是可用状态，没有"仅限员工"的提示，不要求再次登录 |
| QA-identity-009-admin-002 | AC-001 | 同上 | 点击「立即报名」，完成报名；对一件作品投票；提交一条带配图的寄语 | 三个动作都成功 |
| QA-identity-009-admin-003 | AC-002 | 从公司官网（无令牌）打开同一 Celebration 详情页，报名开关打开 | 查看右侧「Event Details」卡片 | 没有「立即报名」按钮，也没有"仅限员工"之类的提示文字；Site、Date、Highlights 照常显示 |
| QA-identity-009-admin-004 | AC-002 | 同上，涂鸦展示开关打开且有作品 | 查看涂鸦展示区 | 作品卡片、作者、说明、票数照常显示；没有任何投票按钮，也没有提示条或提示文字 |
| QA-identity-009-admin-005 | AC-002 | 从官网打开活动详情页，寄语墙已启用且未截止 | 查看寄语墙板块 | 没有「写下你的寄语」按钮，也没有提示文字；已展示的寄语照常显示 |
| QA-identity-009-admin-006 | AC-003 | 外部人员状态 | 在 Celebration 详情页查看所有可点击元素 | 没有任何报名入口，无法弹出报名弹窗 |
| QA-identity-009-admin-007 | AC-003 | 外部人员状态 | 打开涂鸦作品详情，查看是否能投票 | 作品详情与票数可看，没有投票入口；作品票数不变 |
| QA-identity-009-admin-008 | AC-003 | 外部人员状态 | 在寄语墙板块查找提交入口 | 没有任何提交入口，无法弹出寄语弹窗 |
| QA-identity-009-admin-009 | AC-004 | 外部人员状态 | 浏览 Celebration 详情、点开作品详情、查看寄语墙已展示的留言 | 都能正常查看，作品票数可见，没有被整页拦截 |
| QA-identity-009-admin-010 | AC-005 / §8 校验（后端） | 无令牌 | 直接调用报名接口 | 被拒绝并返回"不是员工"（`not_employee`），没有产生报名记录，名单人数不变 |
| QA-identity-009-admin-011 | AC-005 / §8 校验（后端） | 无令牌；某作品有票数 | 直接调用投票接口 | 被拒绝并返回 `not_employee`，票数不变 |
| QA-identity-009-admin-012 | AC-005 / §8 校验（后端） | 无令牌 | 直接调用提交寄语接口（带配图） | 被拒绝并返回 `not_employee`，管理端没有新增留言 |
| QA-identity-009-admin-013 | AC-006 / §8 校验（后端） | 无有效令牌 | 调用报名接口，请求里带上某员工的工号、`viewer_type=employee` 等参数 | 仍被拒绝，不因这些参数放行 |
| QA-identity-009-admin-014 | AC-006 / §8 校验（后端） | 令牌被篡改或来自其他来源 | 调用报名、投票、提交寄语接口 | 都被拒绝 |
| QA-identity-009-admin-015 | AC-007 / §8 校验（后端） | 员工已进入页面（身份为员工），之后令牌过期 | 点击「立即报名」 | 提示"登录已过期，请重新登录"，不是"仅限员工参与"；没有产生报名 |
| QA-identity-009-admin-016 | AC-007 | 同上 | 直接调用投票、提交寄语接口 | 被拒绝并返回"登录已过期"（`session_expired`），与 `not_employee` 区分 |
| QA-identity-009-admin-017 | AC-008 | 员工点击内部系统里的链接，地址带令牌 | 页面加载完成后看地址栏，复制地址分享给他人打开 | 地址栏里不再有令牌；他人用复制的地址打开，按外部人员处理 |
| QA-identity-009-admin-018 | AC-009 | 打开页面，身份确认请求尚未返回 | 查看三个入口 | 三个入口暂不显示，没有任何提示文字；确认为员工后入口出现 |
| QA-identity-009-admin-019 | AC-009 | 模拟身份确认请求失败 | 查看三个入口 | 入口仍不显示（不放开参与）；在原入口位置显示"身份确认失败"与"重试"（涂鸦展示区在区域标题下） |
| QA-identity-009-admin-020 | AC-009 | 接着上一条，恢复网络 | 点击"重试" | 重新确认身份；员工出现入口，外部人员仍看不到入口且没有提示 |
| QA-identity-009-admin-021 | AC-010 | 报名信息展示开关关闭 | 分别以员工、外部人员身份打开详情页 | 两种身份都看不到报名入口，页面上也没有任何提示 |
| QA-identity-009-admin-022 | AC-010 | 报名开关打开，名额已满；外部人员状态 | 查看报名入口 | 没有报名入口，也看不到"报名人数已达上限" |
| QA-identity-009-admin-023 | AC-010 | 报名开关打开，名额已满；员工状态，未报名 | 查看报名入口 | 显示"报名人数已达上限"置灰（原有规则不变） |
| QA-identity-009-admin-024 | AC-011 | 行政登录管理端 | 为一位外部人士代报名、代录入一条带配图的寄语 | 都成功，不受身份限制影响 |
| QA-identity-009-admin-025 | AC-007 | 员工已进入页面，之后令牌过期；用手机打开 | 点击「立即报名」 | 手机上有短提示"登录已过期，请重新登录"，不是毫无反应 |
