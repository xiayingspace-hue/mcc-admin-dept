# 数据统计看板（stats-006-admin）

## 1. 概述

行政查看全部活动的关键运营指标汇总，用于复盘和后续活动规划参考。当前为草稿状态——现有原型中的图表和具体数值均为示例数据，统计口径尚未与行政最终确认。

## 2. 涉及角色

引用 [`ROLES.md`](../../shared/ROLES.md)：仅行政查看，只读。

## 3. 术语与模块归属

依赖 `activity-001-admin`、`registration-004-admin`、`submission-003-admin`、`wall-005-admin`（本模块聚合以上四者的数据，不产生自己的一手数据）。

## 4. 使用场景

- 行政查看近期活动的整体运营情况（活动数量、报名情况、签到率）。
- 行政对比不同活动的参与度，为下次活动规划提供参考。

## 5. 业务流程与状态机

本模块不涉及状态流转，纯聚合展示。

## 6. 数据对象

不产生新的数据对象，均为对 `activity`、`registration`、`submission`、`wall` 现有数据的聚合计算结果（如按活动分组的报名人数、签到率、留言数、投票数）。

## 7. 权限规则

行政只读；本模块不提供任何写操作。

## 8. 校验规则

不适用（只读聚合页面）。

## 9. 页面与状态清单

| 页面 | 需要的状态 |
|---|---|
| 数据统计看板 | normal / loading / empty(尚无任何已发布活动可统计) |

## 10. 验收标准

草稿阶段暂不列 AC，待统计口径确认后补充。

## 11. 已知缺口与非目标

| 缺口 | 谁来定 | 何时前定 |
|---|---|---|
| 具体统计口径（如"签到率"的分母是否包含已取消报名的人数） | 行政 | 正式排期前，本条是本需求转为「已确认」状态的前置条件 |
| 是否需要支持自定义时间范围筛选、导出报表 | 行政 | 正式排期前 |
| 指标聚合是实时计算还是定时任务预计算（数据量大时实时计算可能影响页面加载性能） | 行政 + 开发 | 开发排期前 |
| 某个活动未启用的模块（如未开启涂鸦评选），其对应指标列是显示 0 还是不显示该列 | 行政 | 开发排期前 |
