# 模块 slug 受控表 + 术语表

## 模块 slug（≤10 个，当前 6 个）

| slug | 中文名 | 登记日期 |
|---|---|---|
| `activity` | 活动 | 初始 |
| `module` | 活动模块 | 初始 |
| `submission` | 作品管理 | 初始 |
| `registration` | 报名管理 | 初始 |
| `wall` | 寄语墙 | 初始 |
| `stats` | 数据统计 | 初始 |

新增 slug 前先在此登记，确认业务域命名（而非功能动作命名），再用于文件名。

## 术语表（防同义异名）

| 术语（唯一用词） | 定义 | 禁止使用的同义词 |
|---|---|---|
| 活动模块 / ActivityModule | 一个活动实例启用的某种"玩法"（如涂鸦评选），归属某个 `module` 类型 | "活动插件"、"活动组件"（前端实现细节用词，不进需求文档） |
| 模块库 | `module` 类型的只读参考目录，行政浏览用，不可在此新增类型 | "插件市场"、"模块商店" |
| 布局模板 / layout_template | 决定活动详情页整体页面骨架的枚举值，数量有限、由开发维护 | "页面模板"（易与"模板消息"等概念混淆） |
| 参与范围 | 内部员工里谁能报名/参与（全员/指定部门） | 不要与"外部可见性"混用 |
| 外部可见性 / external_visible | 活动页面是否允许公司外部人员访问 | 不要与"参与范围"混用 |
| 开始展示时间 / display_start_time | 某个活动模块在页面上"第一次出现"的时间点，早于该时间模块完全不渲染 | "生效时间"（易与提交/投票截止时间混淆） |
| 审批进度页 | 活动提交审批后的详情落地页，区分发起人/审批人两种视角 | "审批中心"（本产品明确不做独立审批中心，见 product-overview.md 非目标） |
