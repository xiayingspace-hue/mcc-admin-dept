# 模块 slug 受控表 + 术语表

## 模块 slug（≤10 个，当前 9 个）

| slug | 中文名 | 登记日期 |
|---|---|---|
| `activity` | 活动 | 初始 |
| `module` | 活动模块 | 初始 |
| `submission` | 作品管理 | 初始 |
| `registration` | 报名管理 | 初始 |
| `wall` | 寄语墙 | 初始 |
| `stats` | 数据统计 | 初始 |
| `celebration` | 活动 Celebration（分站点子活动） | REQ-007 |
| `sponsor` | 赞助商管理 | REQ-008 |
| `identity` | 员工身份识别与参与限制 | REQ-009 |

新增 slug 前先在此登记，确认业务域命名（而非功能动作命名），再用于文件名。

## 术语表（防同义异名）

| 术语（唯一用词） | 定义 | 禁止使用的同义词 |
|---|---|---|
| 活动模块 / ActivityModule | 一个活动实例启用的某种"玩法"，挂载在活动上（如 CEO致辞、历史时间轴、周年博客列表、寄语墙），归属某个 `module` 类型 | "活动插件"、"活动组件"（前端实现细节用词，不进需求文档） |
| 模块库 | `module` 类型的只读参考目录，行政浏览用，不可在此新增类型；同时收录挂载在活动上与挂载在 celebration 上的两类模块类型 | "插件市场"、"模块商店" |
| 布局模板 / layout_template | 决定活动详情页整体页面骨架的枚举值，数量有限、由开发维护 | "页面模板"（易与"模板消息"等概念混淆） |
| 参与范围 | 内部员工里谁能报名/参与（全员/指定部门） | 不要与"外部可见性"混用 |
| 外部可见性 / external_visible | 活动页面是否允许公司外部人员访问 | 不要与"参与范围"混用 |
| 开始展示时间 / display_start_time | 某个挂载在活动上的模块在页面上"第一次出现"的时间点（Celebration 上的报名信息、涂鸦展示模块不使用，改由展示开关控制），早于该时间模块完全不渲染 | "生效时间"（易与提交/投票截止时间混淆） |
| 展示开关 | Celebration 上"报名信息""涂鸦展示"两类模块各有一个，控制用户端是否显示该模块及其入口；新建默认关闭，关闭时配置与数据保留 | "启用开关"、"开始展示时间"（后者已不用于这两类模块） |
| 预告海报 | Celebration 的必填图片（JPG/PNG，≤5MB），在即将开始、进行中状态下于用户端详情页左侧完整展示，已结束后不再展示；与"封面图-预告版"（页面顶部大图）是两张不同的图 | "封面图"（易与顶部大图混淆） |
| Celebration 状态 | 由时间自动判定的三种状态：即将开始（开始时间前）、进行中（开始后至结束日期当天）、已结束（过了结束日期，次日 00:00 新加坡时间起）；决定封面、用户端左侧内容和列表筛选 | "已举办"（旧称，已不用） |
| 签到码 | 每条报名记录一个、系统生成的不可猜测的随机码，二维码内容即此码；不含姓名、电话等个人信息；报名取消后失效 | "二维码"（二维码只是它的呈现形式） |
| 签到时间窗口 | 扫码签到被允许的时间段：从 Celebration 开始时间前 6 小时起，到结束日期当天结束（新加坡时间）止；窗口外扫码提示"不在签到时间内" | "签到截止时间" |
| 审批进度页 | 活动提交审批后的详情落地页，区分发起人/审批人两种视角 | "审批中心"（本产品明确不做独立审批中心，见 product-overview.md 非目标） |
| Celebration | 一个活动下、某个 site（地点）举办的一场分站点子活动实例，拥有独立的封面图、文字描述、图片相册，并可挂载"报名信息""涂鸦展示"两类模块；不参与活动审批，创建后立即生效 | "子活动"、"分会场"（不进需求文档，统一用英文 Celebration） |
| Site | Celebration 归属的地点标识（如"新加坡总部站"），仅是 Celebration 的一个字段，不是独立数据对象 | "分会场"、"场地" |
| CelebrationModule | 某个 Celebration 启用的"报名信息"或"涂鸦展示"模块实例，与挂载在活动上的 ActivityModule 是两类不同的挂载记录，共用 `module` 类型定义 | 不要与 ActivityModule 混用 |
| 员工身份 | 访问者是不是员工，由后端根据内部访问令牌里的工号判定，并每次请求实时向 HR 系统核对：状态为 `on the job`、`probation` 的才是员工，其他状态（含已离职）按外部人员处理；员工可以报名、投票、提交寄语，外部人员只能浏览 | "登录状态"、"账号类型"（本产品用户端没有自有账号体系） |
| 内部访问令牌 | 公司内部系统在员工跳转到活动页面时传递的凭证，用来证明访问者是员工；从公司官网进入的访问者没有该令牌 | "工号参数"（工号不能作为身份依据） |
| 参与入口关闭 | 外部人员的页面上，报名、涂鸦投票、提交寄语三个入口不显示，也没有提示文字；与"登录已过期"（员工点击后提示）、"身份确认失败"（显示重试）是不同情形 | "置灰"（本产品不做置灰入口） |
